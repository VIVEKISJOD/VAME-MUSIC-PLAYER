# Contributing

Thanks for wanting to help VAME Music!

- **Found a bug?** Open an issue and use the Bug report template. Say your Android version and what you tapped.
- **Have an idea?** Open an issue with the Feature request template.
- **Want to send code?** Fork the repo, make your change on a branch, and open a pull request.
  Keep changes small, and make sure the app still builds (the workflow builds every pull request).
- No fake features: if something is not finished it should say "not built yet" in the app.
- By sending code you agree it is released under the same license as the project (GPL-3.0).

Be kind and respectful to everyone.
